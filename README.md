### Moment-Jalaali Sample
This is a jalaali datepicker using the official Angular Material for Persian calendars.

1. Copy the `datepicker` folder into your project.

2. Perform these installatins:
    1. Install *Angular Material*
    2. Install *material-moment-adapter*
    ```bash
    ng add @angular/material-moment-adapter
    ```
    3. Install *moment-jalaali*
    ```bash
    npm i moment-jalaali
    ```
3. See `app-component` for the usecase.
